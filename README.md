# 🌐 Dynamic Portfolio

A responsive and dynamic personal portfolio showcasing my skills, projects, achievements, certifications, and resume. Built with modern web technologies to provide a clean and interactive user experience.

## 🚀 Live Demo

🔗 https://dynamic-portfolio-nu-wheat.vercel.app/

---

## ✨ Features

- Responsive Design
- Modern UI/UX
- About Me Section
- Skills Showcase
- Projects Section
- Experience & Achievements
- Resume Download
- Contact Information
- Fast Loading
- SEO Friendly

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Responsive Design
- Vercel (Deployment)

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Adity-code2145/Dynamic-Portfolio.git
```

Go to project folder

```bash
cd Dynamic-Portfolio
```

Open the project

```bash
Open index.html in your browser
```

or use Live Server in VS Code.
